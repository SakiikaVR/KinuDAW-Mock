# KinuUI CSS Animations demo

An RML/RCSS motion gallery exercising KinuUI's browser-compatible animation shorthand, milliseconds, CSS easing aliases, `cubic-bezier()`, fill modes, transforms, delays, and solid border syntax. The third card deliberately uses Animate.css 4.1.1-style `animation-*` longhands with `var()` and `calc()` so the compatibility path is covered by the executable demo.

The visual study is inspired by [yui540/css-animations](https://github.com/yui540/css-animations), used under its MIT license. No original image or video asset is redistributed. The demo markup and artwork in this directory are original and licensed under KinuUI's MIT license.

Build with `RMLUI_SAMPLES=ON`, then run `rmlui_sample_kinu_css_animations`. Use **FREEZE / RESUME** to pause the context clock, **REPLAY** to restart the scene, and **F8** for the RmlUi debugger.
